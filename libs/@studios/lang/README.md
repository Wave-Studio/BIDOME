# @studios/lang
A simple localization plugin with support for variables via {i}

## Loaders
We support the following loaders out of the box:
- YAML
- JSON[C]

## Plugins
If you'd like a loader or variable formatter that isn't already supported you can create/use an external one thanks to our Plugin API.
